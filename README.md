# Acrain-
## QuickNote (macOS app)

A menu bar app for macOS 12+ (Intel and Apple Silicon), in `QuickNote/`.

- `⌥ Space`: write a quick note (`⌘↩` saves, `esc` closes)
- `⌃⌥ S`: capture part of the screen, annotate it, add a note
- `⌃⌥ A`: board of all notes; drag to move, double-click to edit, **Clean Up** to re-grid

Build on a Mac with `./QuickNote/build.sh`, or download the `QuickNote-macOS` artifact from the
"Build QuickNote" GitHub Actions run. Notes are stored in `~/Library/Application Support/QuickNote`.
